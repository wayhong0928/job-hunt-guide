# 求職信撰寫

> 履歷列出你做過什麼，求職信說明為什麼這些經歷適合這個職缺、這家公司。一封好的求職信不長，但每一段都要回答招募者心裡的一個問題。

---

## 一、先搞清楚求職信要做什麼

求職信不是把履歷改寫成段落。招募者已經有你的履歷，求職信要補上履歷說不清楚的三件事：

- 你為什麼應徵這個職缺，不是隨手投遞
- 你的哪一兩項經歷，跟這個職缺的要求最直接相關
- 你對這家公司的了解，以及你想加入的具體理由

什麼時候一定要寫、什麼時候可以省略，可以這樣判斷：

| 情況 | 建議 |
|---|---|
| 職缺公告明確要求附求職信 | 一定要寫，沒附等於資料不齊 |
| 平台或 Email 投遞時有訊息欄位 | 寫一段精簡版，三到五句就好 |
| 轉職、跨領域、有空窗期 | 值得寫，這是說明背景轉折的最好位置 |
| 職缺沒要求、投遞流程也沒有欄位 | 可以省略，把時間花在客製履歷上 |

!!! note "求職信和自傳不一樣"
    台灣平台常見的自傳，是履歷裡的固定欄位，篇幅較長，可以展開完整的故事線。求職信是投遞單一職缺時另外附上的信件，篇幅較短，只談這個職缺。104 投遞時可以另外附上的自我推薦信，也可以用這一頁的結構來寫。自傳的寫法見[求職平台攻略](platforms.md)第三節。

---

## 二、內容結構：四段就夠

一封求職信以一頁為上限，多數情況下四段就能講完。每一段只回答一個問題：

| 段落 | 要回答的問題 | 寫法重點 |
|---|---|---|
| 開頭 | 你是誰、應徵什麼 | 寫出職缺名稱與得知管道，再用一句話說明你的定位 |
| 第二段 | 你憑什麼適合 | 挑一到兩項跟職缺要求最相關的成果，寫出行動與結果 |
| 第三段 | 為什麼是這家公司 | 連結公司公開的產品、服務或職缺描述裡的具體內容 |
| 結尾 | 接下來呢 | 表達面談意願，說明附件內容，簡短道謝 |

### 2.1 開頭：第一句就講應徵的職缺

不要從「您好，我是某某大學某某系畢業生」開始鋪陳。招募者可能同時在看好幾個職缺的應徵資料，第一句就寫清楚你應徵哪個職缺，再接一句定位，例如「具備兩年電商營運經驗，擅長把銷售資料整理成可執行的調整方案」。

### 2.2 第二段：只挑最相關的一兩項

這一段最容易寫成履歷摘要。挑選的原則是回頭看職缺公告：公告裡反覆出現、或排在最前面的要求，就是你要舉證的對象。每一項成果都用履歷寫作那一頁的 APR 句型，寫出行動、專案或問題、結果，見[履歷寫作](resume-writing.md)第二節。

舉兩項講清楚，比列五項每項一句更有說服力。其他經歷招募者可以自己看履歷。

### 2.3 第三段：寫出你查過這家公司

「貴公司是業界領導品牌」這類句子放在任何一封信裡都成立，等於沒寫。比較好的做法是引用公開資訊：公司最近推出的產品或服務、官網上說明的服務對象、職缺描述裡提到的團隊目標，再說明你的經驗和這件事的關聯。

只寫公開查得到的資訊。不要引用從前同事或內部管道聽來的消息，這會讓招募者懷疑你對保密的態度。

### 2.4 結尾：簡短，不要乞求

一到兩句就好：表達希望有機會面談、說明附上的履歷或作品集、感謝對方撥空閱讀。避免「懇請給我一個機會」這類低姿態寫法，也不需要重複前面的內容。

!!! tip "稱謂怎麼寫"
    知道收件人姓名時，用「○經理您好」或對方的職稱。不知道時，中文可以寫「招募負責人您好」，英文常見寫法是 Dear Hiring Manager。

## 三、客製化：每一封至少改三處

同一份求職信換個公司名稱就寄出，招募者通常看得出來。每一封至少要重新寫這三處：

1. 開頭的職缺名稱與公司名稱
2. 第二段挑選的成果，依這個職缺的要求重新挑
3. 第三段的公司連結，每家公司的理由都不同

實用的做法是沿用履歷寫作那一頁的三欄表：職缺要求、你的證據、尚缺什麼。表格左欄排在最前面的兩項要求，就是第二段要舉證的內容。表格右欄如果有明顯缺口，不要在信裡假裝沒有，可以用一句話說明你正在補強的方式。

## 四、常見地雷

- 把履歷內容改寫成段落，沒有新增任何資訊
- 套用舊信忘了改公司名稱或職缺名稱，招募者一眼就會發現
- 只寫自己想要什麼，例如學習機會、成長空間，沒寫能帶來什麼
- 堆疊形容詞，例如「積極、細心、抗壓性高」，卻沒有任何事例支撐
- 超過一頁，或每一段都很長，招募者沒辦法快速掃讀
- 提到前公司的客戶名稱、內部專案代號或未公開資訊
- 信裡的年資、職稱、日期和履歷不一致
- 寫了身分證字號、婚姻狀況等職缺沒要求的個人資料
- 用 AI 工具產生草稿後沒有改寫，整封信都是罐頭式排比句

!!! warning "用 AI 工具草擬的注意事項"
    AI 工具可以幫忙整理段落順序、檢查語氣，但請不要讓它替你編造成果或數字。貼入素材前，先移除真實姓名、公司內部代號、客戶名稱等資訊。草稿完成後逐句重讀，改成你自己會講的話。提示詞的寫法可以參考[工具箱](toolbox.md)第三節。

## 五、通用範本示例

以下範本中的 `⟨⟩` 要換成你自己的內容。範本只是骨架，每一段的句子都應該依職缺重寫。

```text
⟨稱謂⟩您好：

我想應徵貴公司在⟨得知管道⟩刊登的⟨職缺名稱⟩。我具備⟨年資或背景⟩，
擅長⟨與職缺最相關的一項能力⟩。

在⟨前一份工作或專案⟩中，我⟨行動⟩，⟨結果⟩。這段經驗和職缺提到的
⟨職缺要求一⟩直接相關。另外，我曾⟨第二項成果的行動與結果⟩，
可以協助團隊⟨職缺要求二⟩。

我注意到貴公司⟨公開資訊，例如新推出的服務或職缺描述中的團隊目標⟩。
⟨說明你的經驗和這件事的關聯，或你想參與的原因⟩。

隨信附上履歷⟨與作品集連結⟩，希望有機會進一步面談。感謝您撥冗閱讀。

⟨姓名⟩ 敬上
```

下面是套用範本的示範，公司、職缺與經歷都是虛構的通用素材：

```text
招募負責人您好：

我想應徵 A 公司在求職平台刊登的資料分析師職缺。我有兩年零售業營運經驗，
擅長把銷售與庫存資料整理成門市可以直接執行的調整建議。

在前一份工作中，我重整了每週銷售報表的製作流程，把原本需要兩天的彙整
時間縮短到半天，並新增缺貨預警欄位，協助門市主管提早調整訂貨量。這段經驗
和職缺提到的「建立營運報表並提出改善建議」直接相關。另外，我自學 SQL 並
完成一份公開資料集的分析專案，可以協助團隊處理職缺要求的資料擷取工作。

我在貴公司官網看到今年開始提供門市庫存管理服務，這和我過去每天處理的
問題很接近。我希望能把第一線營運的經驗，帶進分析工作裡。

隨信附上履歷與分析專案的連結，希望有機會進一步面談。感謝您撥冗閱讀。

○○○ 敬上
```

!!! note "英文求職信"
    外商或國際職缺通常要求英文求職信，段落結構相同。英文信同樣以一頁為上限，職缺若有指定格式或字數，以職缺說明為準。英文求職信的原文指南，可以從[工具箱](toolbox.md)第四節大學職涯中心清單中，Harvard Extension School 的兩筆履歷與求職信資料開始查。

## 六、寄出前自我檢查

- [ ] 公司名稱、職缺名稱都正確，沒有沿用上一封信的內容？
- [ ] 第一句就寫出應徵的職缺？
- [ ] 第二段的成果對應職缺公告裡最重要的一兩項要求？
- [ ] 第三段引用的是公開資訊，不是空泛的稱讚？
- [ ] 全文在一頁以內，每段都能快速掃讀？
- [ ] 年資、職稱、日期和履歷一致？
- [ ] 沒有前公司機密、客戶名稱或職缺沒要求的個人資料？
- [ ] 檔案格式、寄送方式符合職缺說明的指示？

---

## 七、本頁重點回顧

- 求職信補上履歷說不清楚的部分：為什麼應徵、哪些經歷最相關、為什麼是這家公司。
- 四段結構：開頭講職缺與定位、第二段舉一到兩項成果、第三段連結公司公開資訊、結尾簡短表達面談意願。
- 每一封至少重寫三處：職缺與公司名稱、挑選的成果、公司連結。
- 最常見的地雷是改寫履歷、忘了改公司名稱、只寫自己想要什麼，以及堆疊形容詞卻沒有事例。
- 範本只是骨架，句子要依職缺重寫；AI 工具草擬的內容要自己逐句改過。
